## Sobre o Projeto

O **Help_TI** é um assistente virtual que automatiza o atendimento de suporte técnico para professores e alunos, oferecendo soluções para problemas comuns de TI.

---

## 📥 Instalação

### 1. Clone o repositório

```bash
git clone https://github.com/sizidoro77/help_ti-.git
```

### 2. Acesse a pasta

```bash
cd help_ti
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Configure o arquivo `.env`

```env
OPENAI_API_KEY=sua_chave_aqui
```

---

## 📱 Como Utilizar

### 1. Inicie o chatbot

```bash
node chatbot.js
```

### 2. Escaneie o QR Code

Abra o **WhatsApp** → **Dispositivos conectados** → **Conectar um dispositivo** e leia o QR Code exibido no terminal.

### 3. Comece a conversar

Envie uma mensagem como:

```text
Olá
```

O chatbot apresentará o menu de atendimento automaticamente.

---

## ⚙️ Funcionalidades

- Atendimento via WhatsApp
- Menu interativo
- Respostas automatizadas
- Abertura de chamados
